# 目的

タイマーB・PMD時間機能の実装完了後、二つの指定原典経路を突き合わせ、製品版Bad AppleのMMLを原曲へ近づける。

# 制約

- 小文字 `t`、大文字 `T`、小文字 `c`、大文字 `C`、`%値`を混同しない。
- TH4抽出物とUTF-8 MMLダンプの両方を根拠にする。
- 音楽意味と出力調整を混ぜず、一変更一仮説を守る。
- 現在の製品再生経路とタイマーB所有境界を維持する。
- 関係する製品ファイルは全文を読んでから変更する。
- テストは作成も実行もしない。
- 人間による聴取なしに音楽的採用完了とはしない。
- この台帳はコミット対象にしない。

# 確認済み

- 作業開始時の追跡対象差分はない。
- タイマーB段階1～6、固定小節撤去、SSG拡張デチューンの実装記録がある。
- 現行意味は小文字 `t` が音楽テンポ、大文字 `T` がタイマーB直接値、大文字 `C` が全音符クロック、小文字 `c` が音符、`%値` が直接PMDクロック長。
- YM2608タイマーB通知1回がPMD演奏時計の1クロックを進める。
- `timerplan.md` は641行すべて確認した。末尾のユーザー訂正が旧二分周案より優先される。
- UTF-8原典ダンプは38行すべて確認した。
- 指定された両アーカイブの `ST02.M86` は同一SHA-256 `60e0e4e9742db3d97bd02238f2602ad7f671c71077479d71593e69710be8f130`。
- 構造走査エラーは0、正規化オラクルは11パート、4268イベント。
- 製品A～E・G・Hは3459音すべてで音高・開始位置・長さ・音色タプルが一致する。
- 実効意味の不一致フィールドは現時点の監査出力では音量だけである。
- 監査由来の生成オラクルとPythonキャッシュはユーザーが明示的に許可した。
- 変更許可一覧は `MmlSongBank.kt` だけ。
- 原典59個の直接クロック長のうち、288クロック切断後に残る52個を製品MMLへ復元した。
- B/Cの切断休符は原典イベント境界に従って `%222` と `%66`、D/E/G/Hは `%96` と後続通常8分休符へ分けた。
- Aの `%192` は切断区間内で完全に消費済みなので復元対象外。
- `#LFOSpeed Extend` で原典A～Jの `MXA1 MXB1` と同じ初期モードを既存FM/SSGパートへ与えた。
- G先頭の長さ消費前 `t70` → `t80` を復元した。最終値は初期値と同じ80で、架空時間区間はない。
- 変更前後で各置換区間のPMDクロック合計は同じ。曲窓は4992クロックのまま。
- `git diff --check` は成功した。製品差分は `MmlSongBank.kt` だけ。
